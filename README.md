# Antham Enterprise - Official Corporate Website

Static, high-performance website for **ANTHAM ENTERPRISE** (Howrah, West Bengal), a multi-service government contractor, institutional supplier, and contract execution enterprise.

Built strictly with **HTML5, CSS3, and Vanilla JavaScript**—zero external frameworks, no server dependencies, and designed specifically for GitHub Pages hosting.

---

## 🚀 GitHub Pages 1-Minute Deployment

1. Create a repository on GitHub (e.g. `antham-enterprise`).
2. Upload the files maintaining the directory structure:
   - Root files: `index.html`, `about.html`, `services.html`, `contact.html`, `robots.txt`, `sitemap.xml`, `README.md`
   - `assets/css/style.css`
   - `assets/js/script.js`
   - `assets/images/logo.svg`
   - `favicon/favicon.svg`
3. Go to **Settings > Pages** in your GitHub repository.
4. Select `main` (or `gh-pages`) branch, choose `/ (root)`, and click **Save**.
5. The website will be live in 1–2 minutes at `https://<USERNAME>.github.io/<REPOSITORY>/`.

---

## ⚙️ Replacing Placeholders

1. **Contact Details**: In `assets/js/script.js`, set:
   - `businessWhatsAppNumber = "91XXXXXXXXXX"` (your 10-digit number with country code `91`, no plus `+`).
   - `businessEmailAddress = "your.actual.email@domain.com"`.
2. **HTML Content**: Replace `[PHONE NUMBER]`, `[WHATSAPP NUMBER]`, `[BUSINESS EMAIL]`, and `[REGISTERED ADDRESS PLACEHOLDER]` across the HTML pages.
3. **Credentials**: Update `[UDYAM-WB-REGISTERED]` and `[GSTIN: 19XXXXXXXXXXXZX]` in `index.html` with your verified business identification numbers.
